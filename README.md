# 법령점검 도우미

사업자의 세무 숫자·조문이 법제처 원문과 같은지 대조해서, 달라진 점만 알려 주는 **비공식 도우미**의 규칙 파일 저장소예요.

## 꼭 알아 두세요
- 신고·납부를 대신해 주지 않아요. 세무대리·세무상담도 하지 않아요.
- 목록에 있는 값은 비교용이에요. 원문을 읽지 못하면 대조할 수 없다고 말해요.
- 비밀번호·인증서·주민등록번호는 받지 않아요.
- 참고용 안내이며, 최종 판단은 직접 하시고 중요한 건 세무사와 상의해 주세요.

## 들어 있는 파일
| 파일 | 내용 |
|---|---|
| `law-rules.md` | 법령점검 도우미 업무 규칙 |
| `law-start.md` | 법령점검 도우미 시작하기 (새로 대화를 시작할 때 쓰는 안내) |
| `law-list.md` | 법령점검 도우미 대조 목록 (비교용 값) |
| `MANIFEST.txt` | 위 세 파일이 맞는 판인지 확인하는 목록 |

## 이 저장소를 쓰는 방법
공유 카드로 도우미를 받으면, 도우미가 대화를 시작할 때 `MANIFEST.txt`를 받아 파일 내용이 목록과 같은지 확인한 뒤에 규칙을 따라요. 파일을 직접 고쳐 쓰지 마시고, 새 판이 나오면 도우미 안내에 따라 새로 받아 주세요.
